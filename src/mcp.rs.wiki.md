# src/mcp.rs

**Role:** Stdio JSON-RPC MCP adapter over `src/api.rs`.

`tool_schema` describes one tool. `handle_message` answers one JSON-RPC request. `serve_stdio` reads messages from stdin. `configure` reads `WIKIFIER_TOOLS` / `WIKIFIER_DISABLE` and the AGENTS.md `agent-tools` block into a `GroupState` (exit 2 on an env mistake). Before each message `refresh` stats AGENTS.md and reloads it; when the tool list changed, `serve_stdio` writes `LIST_CHANGED` before the response. `active` and `groups_state` read the current state. `initialize` always advertises `tools.listChanged`. `tools/list` lists only the tools `active` allows, `initialize` adds an `instructions` line and `list_core_tools` a `groups` line when either switch is set, and a call to a hidden tool returns `ToolDisabled`. `tools/call` sets `isError` when the payload has `success: false`. `resources/read` serves the library, health, pending, and journal resources. `prompts/get` returns a short user message. Each call runs on a thread and stops waiting after `WIKIFIER_MCP_DEADLINE_S` seconds (default 60). A timeout payload has `timed_out` and `may_still_complete`.

A `tools/call` that leaves out a required argument other than `project_root` (or sends it empty) gets `InvalidArguments` naming the missing field, the accepted fields, and the fields received. `project_root` falls back to `WIKIFIER_PROJECT_ROOT`, then the cwd. `update_maps` omits the edge list unless `edges: true`; `edges_persisted` still gives the count. `health` takes `limit` (adds `entries_total` when it cuts) and `summary`. `session_bootstrap` and `get_project_status` cap `files` at `MCP_BOOTSTRAP_FILES` (100) unless the call passes `limit` (`0` lists all).
