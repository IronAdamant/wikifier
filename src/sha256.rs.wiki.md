# src/sha256.rs

**Role:** Std-only SHA-256 for content identity.

`sha256` returns the digest, `sha256_hex` the hex string, and `sha256_prefixed` the `sha256:<hex>` form stored in `file_health.json`. `content_sha256_prefixed` hashes with CRLF read as LF, so a Windows `core.autocrlf` checkout matches a baseline hashed from LF. `file_sha256_prefixed` reads a file and returns its content hash.
