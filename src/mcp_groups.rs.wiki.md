# src/mcp_groups.rs

**Role:** MCP tool groups and the on/off switches from the suite's tool-group convention.

`GROUPS` puts every MCP tool in one group: `core` (always on, including `update_maps`), `notes`, `health`, `map`, `cycles`, `status`. `group_of` names a tool's group. `TOOLS_VAR` is `WIKIFIER_TOOLS` (allowlist, `all` accepted) and `DISABLE_VAR` is `WIKIFIER_DISABLE` (applied after it). `Selection::parse` and `Selection::from_env` read them (case and spaces ignored, empty means unset) and refuse an unknown name, or `core` or a core tool in `WIKIFIER_DISABLE`, with the one-line message the server prints before exiting 2. `Selection::resolve` combines the environment with an `AgentTools` block, key by key (env wins), and turns block mistakes into warnings. `AgentTools::parse` reads the first fenced `agent-tools` block of an AGENTS.md (backtick or tilde fences, nested fences skipped) and keeps only `wikifier:` lines. `Source` says whether a key came from the environment or the block. `Selection::all` is the unfiltered default. `enabled` exposes the tool set for change detection. `allows`, `refusal`, `active_groups`, `summary`, and `is_filtered` drive `src/mcp.rs`.
