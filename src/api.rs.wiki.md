# src/api.rs

**Role:** Agent-facing operations. The CLI and MCP server both call this module.

`update_maps_run` walks the map roots, skips unchanged files by size and mtime, commits the text cache, then writes `library.md` and the folder cards. `--directory`, `--max-files`, and `--stream` are arguments of that run. A file budget leaves the map incomplete and the next run resumes.

`record_deletion` journals the removal, marks the health row Red, and drops the file from the graph. `record_changes_opts` takes the git change list and matches reasons by exact path, directory prefix, then glob. `mark_green` checks Python, JS/TS, and Rust public names against the wiki and removes that file's pending line. Rust names come from `rust_public_symbols`.

`Cap` is the one parser for every count cap (`limit`, `max_items`, `max_files`, `WIKIFIER_CHECK_CHANGES_MAX`): `Cap::parse` and `Cap::from_flags` give `Default` (absent or not a whole number), `All` (`0`), or `First(n)`; `max` turns it into the API's `Option<usize>`, where the default is every item.

Public names: `Cap`, `parse`, `from_flags`, `max`, `MapRun`, `VERSION`, `MCP_TOOLS`, `update_maps`, `update_maps_opts`, `update_maps_run`, `mapped_edges`, `load_dependencies`, `dependency_report`, `load_dependents`, `list_paths`, `session_bootstrap`, `suggest_next_actions`, `check_changes`, `prepare_edit`, `record_change`, `mark_green`, `health`, `read_health`, `read_journal`, `cache_status`, `validate`, `cycles`, `verify_wikis`, `record_changes`, `record_changes_opts`, `record_deletion`, `heal_stubs`, `prune_health`, `prune_health_opts`, `prune_pending`, `stale_wikis`, `prune_barrels`, `metrics_snapshot`, `healing_stats`, `resolution_diagnostics`, `barrel_reports`, `incremental_status`, `serve_once`, `serve_loop`, `monitor_loop`, `monitor_passes`, `HeartbeatOptions`, `from_root`, `heartbeat_ticks`, `daemon_ctl`, `dispatch`, `CLI_COMMANDS`, `ensure_root`, `seed_source_hashes`, `list_paths_at`, `session_bootstrap_scoped`, `suggest_next_scoped`, `health_view`, `cycles_view`, `stale_wikis_in`, `daemon_command`.

`suggest_next_scoped` adds `review_modularity` when a mapped file is over the line-count or fan-in threshold from `project_config`, and puts `changed_lines` on a Yellow content-change action. `check_changes` fills those ranges from the mark-green snapshot (`drift::ranges_since_baseline`) and refreshes `.wikifier_staging/modularity.json`. `monitor_loop` repeats that cheap pass. `heartbeat_ticks` is the daemon loop: `HeartbeatOptions::from_root` reads `health_interval_s` and `maps_interval_s`, and a short health interval does not run `update_maps` on every tick. `monitor_passes` runs the cheap pass a fixed number of times and does not map.

`serve_loop` answers the JSON API, `/__wikifier/status`, dashboard `run` and `shutdown`, and project files such as `file_health.json` and `library.md`. `monitor_loop` and `daemon_ctl` (`start`, `stop`, `status`, `run`) are the other standing processes. `heal_stubs` with `dry_run` counts long Initial stubs and does not write. `seed-health` returns `HealthError` when the write fails. `verify_wikis_under` can limit the check to one file or directory. `search-journal --file` keeps one path. File arguments go through `scope::rel_arg`, so `src.rs`, `./src/a.rs`, and an absolute path under the root all name the `src/a.rs` row. `prepare_edit`, `dependency_report`, `load_dependents`, and `get_file_wiki` return `FileNotFound` (with a `list_paths` hint) for a path that is neither on disk nor in the map, and `ValueError` for an empty path. `health --limit N` keeps N entries and reports `entries_total`. `init` seeds `map_paths.txt` and `monitored_paths.txt` from `scope::default_map_roots`. Content hashes for health baselines use `content_sha256_prefixed`, so CRLF and LF copies of a file match. `check_changes` and health seeding reuse a mapped file's cache hash when size and mtime match (`cache::hash_if_unchanged`); `cycles` loads edge flags only for files in a cycle; `update_maps_run` skips `maps_out::write` when the commit changed nothing and the artifacts are current; `session-bootstrap --limit` caps `files` and adds `files_total`. Mutating commands take `.wikifier_staging/.lock` before the cache lock. `prune_health` and `prune_pending` keep files named in `monitored_paths.txt`. `prune-health --deleted-missing` also drops rows whose path is no longer a file.
