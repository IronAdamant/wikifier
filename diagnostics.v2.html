Extending Wikifier

Add a language

  1. Create wikifier/parsers/<lang>.py exposing parse_<lang>_imports(path) -> List[Dict] with the shared edge contract (contracts.py).
  2. Add its suffixes to candidates.SOURCE_EXTS and route them in api._parser_for.
  3. Add a fixture to tests/accuracy_fixtures.py; scripts/parser_accuracy.py must stay at 1.00 / 1.00.
  4. Stdlib only — no tree-sitter or other runtime dependency.

Add a command or tool

  1. Implement it once in wikifier/api.py; return {"success": …}, never raise across the boundary.
  2. Expose it in cli.py (argparse) and, if agents need it, as a thin wrapper in mcp/server_impl.py.
  3. Document it in skills/run.md; add a regression test.
  4. Launchers stay 15-line wrappers around python -m wikifier.
