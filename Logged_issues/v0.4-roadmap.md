# v0.4 Roadmap Tracking

**Status**: Planning → Execution  
**Focus**: Agent-to-Agent Codebase Memory Layer  
**Success Definition**: See `Success Markers` below

## Vision

Make Wikifier a reliable, structured memory system that LLMs and agents can trust to maintain long-term understanding of codebases across sessions — primarily to reduce token usage and improve focus on relevant files.

Human-facing features (especially the HTML dashboard) are deprioritized in v0.4.
