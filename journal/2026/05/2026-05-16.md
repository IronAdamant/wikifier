## Known Issues Discovered Immediately
- validate / check-changes only populate health for files under explicit root= "recipe-lab-dogfood/..." because find . does not descend dir symlinks (no -L). When root=".", dogfood files invisible.

- MCP server (FastMCP) is hardcoded to WIKIFIER_ROOT, so get_project_status etc always report on Wikifier itself, not the dogfood target. Shell CLI is the only way to target RecipeLab.
- This already challenges "production-grade MCP for agents" on external codebases.
